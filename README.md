# DSH 工具集（树剪整理脚本）

> 「树剪」文件整理与 DeepSeek Harness 桌面化过程中用到的脚本工具。

## 📁 文件说明

| 文件 | 用途 | 用法 |
|------|------|------|
| `organize_treecut.ps1` | 树剪文件**一键整理主脚本**（全盘移动归类） | 管理员 PowerShell 运行 |
| `finish_treecut.ps1` | **补完脚本**（处理中断/遗漏步骤，幂等可重复） | 管理员 PowerShell 运行 |
| `一键整理树剪.bat` | 一键整理启动器 | 右键 → 以管理员身份运行 |
| `补完整理.bat` | 补完启动器 | 右键 → 以管理员身份运行 |

## 📂 整理目标结构（E:\树剪整理）

```
E:\树剪整理\
├── 01_主程序源码\      ← 树剪软件相关文件（代码+素材输出）
├── 02_安装程序\        ← TreeCut_v13 已安装程序 + v13 安装分卷
├── 03_草稿视频导出\    ← 草稿视频
├── 04_文档资料\        ← 说明文档/导图/升级说明
└── 05_清理备份\        ← 旧备份/旧版本/重复文件（冷藏区，确认后可删）
```

## ⚠️ 注意事项

- **需要管理员权限**：E 盘根目录 ACL 为 Users 只读，创建 `E:\树剪整理` 必须提权
- **编码约定**：`.bat` 使用纯 ASCII（避免系统代码页差异解析乱码）；`.ps1` 使用 UTF-8 BOM（PowerShell 5.1 兼容）
- 脚本全部使用绝对路径，移动文件前自动检查存在性，操作记录写入 `E:\树剪整理\_整理日志.txt`
- G 盘 v12.2 完整部署（7.2GB）为跨盘复制，耗时数分钟属正常

## 🔧 其他脚本

- `打包DSH桌面版.bat`：electron-builder 打包 DSH 桌面版（需管理员，可选）
- 树剪模型下载脚本在 `treecut` 仓库中（`dl_model.bat` 等）
